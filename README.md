# Audit-

Site profissional desenvolvido para apresentar minha experiência e atuação na área de auditoria de contas hospitalares, além de facilitar o contato com pessoas interessadas em conhecer e contratar meus serviços.


## Demonstração Online

A aplicação está disponível em:

➡️ auditoria-production-bc5d.up.railway.app

## 🛠️ Tecnologias utilizadas

* React 19 — construção da interface
* TypeScript — tipagem e desenvolvimento
* Vite — criação e execução do projeto
* React Router — navegação entre páginas
* Tailwind CSS — estilização da interface
* Lucide React — ícones
* Node.js + Express — backend e processamento das solicitações
* API do Telegram — envio das mensagens do formulário
* Figma — prototipação e desenvolvimento inicial da interface
* Git e GitHub — versionamento e hospedagem do código
* Railway — deploy da aplicação

## 📩 Integração com Telegram

O formulário de contato possui integração com a API do Telegram. Após o preenchimento e envio, os dados são processados pelo backend e encaminhados automaticamente para um bot do Telegram.

## Como executar localmente

```bash
git clone https://github.com/Lascoski/auditmed.git
cd audit
npm install
npm run dev
```

http://localhost:5173
