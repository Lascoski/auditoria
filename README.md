## AuditMed

Sistema desenvolvido para auxiliar na auditoria de contas hospitalares, permitindo análise de cobranças, inconsistências e acompanhamento de serviços.

## Demonstração Online

A aplicação está disponível em:

➡️ site-auditoria.vercel.app

## 🛠️ Tecnologias utilizadas

- React
- TypeScript
- Vite
- CSS
- Vercel (Deploy)

## Como executar localmente

```bash
git clone https://github.com/Lascoski/auditmed.git
cd auditmed
npm install
npm run dev
```
http://localhost:5173
```
## 🌐 Deploy

Este projeto foi publicado utilizando a plataforma **Vercel**, demonstrando a configuração e publicação de aplicações React/Vite em ambiente de produção.
