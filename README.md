## AuditMed

Sistema desenvolvido para auxiliar na auditoria de contas hospitalares, permitindo análise de cobranças, inconsistências e acompanhamento de serviços.

## Demonstração Online

A aplicação está disponível em:

➡️ auditoria-production-bc5d.up.railway.app

## 🛠️ Tecnologias utilizadas

*React 19 — construção da interface
*TypeScript — tipagem e desenvolvimento
*Vite — criação e execução do projeto
*React Router — navegação entre páginas
*Tailwind CSS — estilização da interface
*Lucide React — ícones
*Figma — prototipação e desenvolvimento inicial da interface
*Git e GitHub — versionamento e hospedagem do código
*Railway — deploy da aplicação


## Como executar localmente

```bash
git clone https://github.com/Lascoski/auditmed.git
cd auditmed
npm install
npm run dev
```
http://localhost:5173
```
## 🌐 Deploy

Este projeto foi publicado utilizando a plataforma **Vercel**, demonstrando a configuração e publicação de aplicações React/Vite em ambiente de produção.
